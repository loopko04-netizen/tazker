# تذكير — تطبيق ملاحظات محلي

مشروع React Native / Expo لتطبيق ملاحظات عربي بسيط، يعمل محلياً دون حساب أو اتصال بخادم.

## المواصفات
- Expo SDK 52، React Native 0.76.3، React 18.3.1.
- JavaScript / JSX، Expo Router 4.
- SQLite للتخزين الدائم على الهاتف.
- Zustand لإدارة الحالة.
- واجهة RTL وقائمة عمودية.
- إنشاء وتعديل تلقائي للملاحظات.
- بحث داخل العناوين والمحتوى.
- تثبيت الملاحظات.
- حذف واستعادة من قاعدة البيانات.
- تبديل فاتح/داكن داخل الواجهة.

## التشغيل
```bash
npm install
npx expo start
```

## بناء Android
```bash
npm install
npx eas-cli build --platform android --profile preview
```

## الخطوط
تم تجهيز `assets/fonts/` لوضع ملفات Thmanyah Sans عند توفيرها:
- `ThmanyahSans-Black.ttf`
- `ThmanyahSans-Medium.ttf`
- `ThmanyahSans-Light.ttf`

لم تُضمّن ملفات الخطوط لأنها غير متاحة ضمن ملفات المشروع الحالية. الواجهة تعمل بخط النظام إلى حين إضافتها وربطها عبر `expo-font`.

## التخزين والخصوصية
جميع الملاحظات محفوظة في قاعدة SQLite داخل مساحة التطبيق على الجهاز. لا توجد أي طلبات شبكة أو مزامنة سحابية في هذا الإصدار. حذف التطبيق من الهاتف قد يؤدي إلى حذف بياناته المحلية؛ يُنصح بتوفير تصدير/نسخ احتياطي في مرحلة لاحقة.
